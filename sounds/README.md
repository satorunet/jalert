# sounds/

警報音の音声ファイルを置くフォルダです。**このリポジトリには音声ファイルは含まれていません。**

| ファイル名 | 内容 |
|---|---|
| `eew.mp3` | 緊急地震速報のチャイム・音声 |
| `missile.mp3` | 国民保護サイレン・音声（ミサイル発射情報） |

- mp3 / m4a / wav / ogg のどれでも読み込みます。
- ファイルが無い場合は、ブラウザ内で合成した代わりの音（チャイム風・サイレン風＋読み上げ）が鳴ります。
- 実際の警報音を使う場合は、権利者・配布元の利用条件を確認し、必要な許可を得てから配置してください。
